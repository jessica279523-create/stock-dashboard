# 我的台股每日簡報(進階版)

用 GitHub Actions 每天自動抓取台股數據,產生一個屬於妳自己的每日更新網站。

## 這次更新的 6 個新功能
1. **監控股分類**:自選清單依產業別分組(半導體、航運、金融、面板、電子代工/零組件、傳產、民生消費、ETF)
2. **今日重點摘要**:自動抓出「今天漲最多」與「跌最多」的標的,顯示在頁面最上方
3. **大漲大跌警示**:當日漲跌幅絕對值 ≥ 5% 的股票,會用 🔥 圖示 + 特殊底色標示
4. **本益比 / 殖利率**:每檔監控股額外顯示 PE 本益比與現金股利殖利率(部分股票可能抓不到,會顯示 `--`)
5. **損益走勢圖**:累積每天的總市值紀錄(存在 `history.json`),畫成一條簡單的折線圖
6. **排序功能**:監控清單依當日漲跌幅由高到低排序,同一產業內最亮眼的股票會排在最前面
7. **紅漲綠跌**:改成台股習慣的顏色(上漲紅色、下跌綠色)
8. **個股詳情頁**:點擊任一檔股票的卡片或代碼,會進到 `docs/stocks/{代碼}.html` 子頁面,包含:
   - **簡介**:公司名稱、產業分類
   - **走勢**:近 3 個月收盤價折線圖
   - **價量**:近 10 個交易日的開高低收+成交量
   - **財務**:EPS、營收、毛利率、淨利率、ROE、市值、本益比、殖利率
   - **股利**:近期股利發放紀錄

### 目前沒有做的功能(技術上做不到或需要付費數據源)
- **五檔**:因為網站是每天排程更新一次,不是即時盤中報價,做「五檔」意義不大
- **上下游**:沒有結構化的公開免費資料源,無法自動化
- **卷商買賣(分點)**:台灣沒有免費公開 API,市面上做這個的都是付費籌碼服務
- **明細(逐筆成交)**:需要即時逐筆資料,免費公開資源難以穩定取得
- 如果之後想加上**外資/投信/自營買賣超、融資融券、公告、行事曆、盤後零股**,這些有公開資料源但需要額外串接,可以再跟 Claude 說一聲繼續擴充


## 設定步驟(跟之前一樣)
沿用先前的 GitHub repo 與 GitHub Pages 設定,不需要重新建立,只需要把這次更新的檔案覆蓋上傳:
- `fetch_and_render.py`
- `render.py`
- `.github/workflows/update.yml`

上傳後,到 **Actions** 頁面點 **Run workflow** 手動跑一次,確認新功能有正常顯示。

## 關於 `history.json`
- 這是第一次執行時會自動新建的檔案,用來累積每天的總市值紀錄
- 最多保留 90 天資料,超過會自動捨棄最舊的
- **重要**:GitHub Actions 的 workflow 已經加上 `git add history.json`,如果之前用的是舊版 `update.yml`,記得也要更新這個檔案,不然歷史紀錄不會被存下來

## 之後想調整持股或監控清單怎麼辦?
打開 `fetch_and_render.py`,修改最上面的 `HOLDINGS`(持股)和 `WATCHLIST`(監控清單)這兩個區塊:
- `HOLDINGS`:需要 `code`、`name`、`shares`、`cost`
- `WATCHLIST`:需要 `code`、`name`、`sector`(產業分類,用來分組顯示)

改完存檔後上傳(push)到 GitHub 就會生效。

## 想調整「大漲大跌」的警示門檻?
打開 `fetch_and_render.py`,找到 `HOT_MOVE_THRESHOLD = 5.0` 這一行,把 `5.0` 改成妳想要的百分比(例如改成 `3.0` 代表漲跌超過3%就標記)。

## 資料來源說明
- **個股報價**:優先使用台灣證交所官方即時報價 API(mis.twse.com.tw),失敗才退回 yfinance
- **大盤指數**:優先使用 TWSE 官方 MIS 特殊代碼(t00/o00),失敗才退回 yfinance(`^TWII` / `^TWOII`)
- **本益比/殖利率**:來自 yfinance 的個股基本資料,更新頻率與正確性不保證,僅供參考
- 這些都是公開數據,可能會有些微延遲,僅供個人參考學習,不構成投資建議
